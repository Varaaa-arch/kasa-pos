# POS System

Modern Point of Sale system with thermal printer integration.

## Project Goal

Membangun sistem POS yang dapat menangani transaksi penjualan
dan terintegrasi dengan thermal receipt printer melalui USB.

## Hardware

- Printer: BLUEPRINT BP-LITE58
- Interface: USB + Bluetooth
- Paper: ~57 mm
- Protocol: ESC/POS

## Planned Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Go
- PostgreSQL

### Printer
- Go Print Agent
- USB
- ESC/POS
